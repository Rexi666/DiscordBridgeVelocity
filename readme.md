# ⭐ DiscordBridgeVelocity — The Ultimate Bridge Between Discord & Velocity ⭐

**DiscordBridgeVelocity** is the perfect plugin for creating a **stable, modern, and fully customizable** connection between your Velocity proxy and Discord.  
Easily link your Minecraft network with a powerful Discord bot, enabling account linking, chat synchronization, role syncing, and much more.

✔️ **Velocity** proxy 
✔️ Optional **LuckPerms** integration 
✔️ Optional **Litebans** integration 
✔️ Optional **VelocityUtils** integration

---

## 🔗 Key Features

### 🤖 Fully Configurable Discord Bot
- Customize bot **status**, **activity**, **description**, and more.
- Admin commands available directly from Discord.

---

### 🔐 Minecraft ↔ Discord Account Linking
Let your players verify their identity with ease.

- Simple linking command for players.
- Secure, fast, and easy to use.
- Fully customizable messages.

**Benefits of account linking:**
- Ensures true identity between Discord and Minecraft.
- Allows role syncing with LuckPerms integration.
- Enables restricted channels or features for verified users only.

---

### 🛡️ Automatic Role Sync (LuckPerms)
If you use **LuckPerms**, the plugin becomes even more powerful:

- Sync Minecraft groups to Discord roles.
- Roles update automatically when a player’s rank changes.
- Keeps your Discord roles always accurate and organized.

---

### 💬 Discord ↔ Minecraft Chat Bridge
Players can communicate from anywhere.

- Messages from **Discord to Minecraft**.
- Fully customizable formatting.

Perfect for global chat, staff chat, or community channels.

---

### ⚙️ Additional Features
- Modular system for Velocity.
- Clean, easy-to-read configuration files.
- Discord Counter Stats for online players.

---

## 🧪 Requirements
- Java 17+
- Velocity proxy
- Discord bot token
- LuckPerms (optional for role sync)
- Litebans (optional for ban sync)
- VelocityUtils (optional for enhanced features)

---

## 📦 Installation
1. Place **DiscordBridgeVelocity.jar** in your Velocity `/plugins` folder.
2. Restart your proxy.
3. Configure your bot in `config.yml`.
4. Use `/discordbridge reload` and enjoy the full integration!
